========================================================================
VLAN (Virtual LAN)
========================================================================

하나의 물리 스위치를 논리적으로 여러 네트워크로 나누어
브로드캐스트 도메인을 분리하는 기술.


------------------------------------------------------------------------
1. VLAN ID 범위
------------------------------------------------------------------------

1             : Default VLAN (기본으로 모든 포트가 속함, 삭제 불가)
2 ~ 1001      : Ethernet 환경 (일반 범위, 생성/삭제 가능)
1002 ~ 1005   : FDDI, Token-Ring 환경 (예약됨, 삭제 불가)
1006 ~ 4094   : 확장형 Ethernet 환경 (확장 범위)


------------------------------------------------------------------------
2. VLAN 생성 (VLAN DB에 추가)
------------------------------------------------------------------------

Switch(config)# vlan 10
Switch(config-vlan)# name SALES
Switch(config-vlan)# exit


------------------------------------------------------------------------
3. Access 포트 설정 (스위치 <-> 컴퓨터)
------------------------------------------------------------------------

하나의 VLAN만 전달하는 포트.

Switch(config)# interface fastEthernet 0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10

여러 포트를 한 번에 설정할 때

Switch(config)# interface range fastEthernet 0/1 - 5
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10


------------------------------------------------------------------------
4. Trunk 포트 설정 (스위치 <-> 스위치)
------------------------------------------------------------------------

여러 VLAN의 트래픽을 태그(802.1Q)를 붙여 함께 전달하는 포트.

Switch(config)# interface gigabitEthernet 0/1
Switch(config-if)# switchport trunk encapsulation dot1q
Switch(config-if)# switchport mode trunk

* switchport trunk encapsulation dot1q 는
  ISL과 dot1q를 모두 지원하는 스위치(3560, 3750 등)에서만 입력
* 2960처럼 dot1q만 지원하는 스위치는
  이 명령어 없이 바로 switchport mode trunk


------------------------------------------------------------------------
5. 확인 명령어
------------------------------------------------------------------------

# show vlan
# show vlan brief
  -> VLAN 목록과 포트 할당 확인 (Catalyst 스위치, 패킷 트레이서)

# show vlan-switch
  -> GNS3에서 라우터에 스위치 모듈(NM-16ESW)을 쓸 때

# show interfaces trunk
  -> Trunk 포트와 허용 VLAN 확인


------------------------------------------------------------------------
6. 캐시 / 테이블 초기화
------------------------------------------------------------------------

[컴퓨터] cmd 창 (관리자 권한)
  arp -a      -> ARP 캐시 확인
  arp -d *    -> ARP 캐시 초기화

[스위치]
  # clear mac address-table dynamic   -> MAC 주소 테이블 초기화
  # clear mac-address-table           -> 구버전 IOS (패킷 트레이서 등)

* 스위치는 ARP 캐시가 아니라 MAC 주소 테이블을 지우는 것
