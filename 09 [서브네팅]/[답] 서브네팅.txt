# 서브네팅 정답 및 해설

> 서브넷 수 기준 : 2^n >= 필요한 서브넷 수 (n = 빌리는 비트 수)
> 호스트 수 기준 : 2^h - 2 >= 필요한 호스트 수 (h = 남기는 호스트 비트 수)
> 서브넷 제로 포함 (첫 번째 서브넷 = 원래 네트워크 주소)

------------------------------------------------------------------------

## 정답 1

12.15.10.100/8 → 2개 서브넷 → 1비트 빌림 → /9

- Subnet Mask : 255.128.0.0
- 두 번째 Network 주소 : 12.128.0.0
- 할당 가능한 IP 주소 : 12.128.0.1 ~ 12.255.255.254
- 브로드캐스트 주소 : 12.255.255.255

해설 : 블록 크기(2번째 옥텟) 256 - 128 = 128 → 12.0.0.0, 12.128.0.0

------------------------------------------------------------------------
